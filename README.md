# OFW Dormitory System

Offline PHP and MySQL application for XAMPP.

## Phase 0 installation

1. Start **Apache** and **MySQL** from the XAMPP Control Panel.
2. Open `http://localhost/phpmyadmin`.
3. Choose **Import**.
4. Select `database.sql` from this project folder.
5. Click **Import** / **Go** and confirm that `ofw_dormitory_system` appears in the left sidebar.
6. Open `http://localhost/dormitory-system/` to confirm the project placeholder loads.

No user account is inserted yet. Phase 1 will create the first admin account using a securely hashed password.
